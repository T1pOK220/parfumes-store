# Roadmap — Pаrfume Store

## Тиждень 3 — Backend та база даних
- створити структуру бази даних;
- створити таблиці users, perfumes,orders,orderItmes,cart,cartItmes,favourites;
- реалізувати підключення Backend до бази даних;
- створити базовий API для отримання парфумів.

## Тиждень 4 — Авторизація
- реалізувати реєстрацію користувача;
- реалізувати авторизацію;
- додати JWT;
- реалізувати розподіл ролей «Покупець» та «Адміністратор».

## Тиждень 5 — Каталог та товари
- реалізувати CRUD для парфумів;
- додати пошук;
- додати фільтрацію та сортування;
- створити сторінку детальної інформації про парфум.

## Тиждень 6 — Кошик та замовлення
- реалізувати кошик;
- додати зміну кількості товарів;
- реалізувати створення замовлення;
- додати перегляд історії замовлень;
- реалізувати зміну статусу замовлення адміністратором.
