# Ubiquitous Language — глосарій термінів

## 1. User

Користувач магазину, який може переглядати товари, додавати їх до обраного, формувати кошик та оформлювати замовлення.

## 2. Parfume

Парфумерний товар магазину, який має назву, бренд, ціну, об'єм, тип аромату та кількість на складі.

## 3. Cart

Кошик користувача, у якому зберігаються товари, вибрані для подальшої покупки.

## 4. CartItem

Окремий парфум та його кількість, додані до кошика.

## 5. Order

Оформлене замовлення, яке містить один або декілька товарів та має певний статус.

## 6. OrderItem

Окремий парфум у складі замовлення із зазначеною кількістю та ціною.

## 7. Price

Вартість однієї одиниці парфуму.

## 8. Stock

Кількість одиниць конкретного парфуму, доступних для продажу.

## 9. Favourite

Парфум, який користувач додав до списку обраних товарів.

## 10. Order Status

Поточний стан замовлення. У прототипі використовуються статуси `created` та `cancelled`.

## Особливості термінів у різних піддоменах

Термін **Parfume** використовується для позначення товару в каталозі. У контексті замовлення цей самий товар представлений як **OrderItem**, який додатково містить кількість та ціну на момент оформлення замовлення.

Тому `Parfume` та `OrderItem` не є взаємозамінними термінами:

- **Parfume** — товар каталогу з актуальною ціною та залишком на складі.
- **OrderItem** — позиція конкретного замовлення із зафіксованою ціною та кількістю.

Це дозволяє уникнути неоднозначності під час роботи з різними частинами системи.
